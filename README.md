# ONG Esperança - Single Page Application (SPA)

Projeto de uma aplicação web responsiva desenvolvida para a **ONG Esperança**, com o objetivo de divulgar causas sociais, projetos da instituição e permitir o cadastro de voluntários.

## 🚀 Tecnologias Utilizadas
- **HTML5** (Estruturação semântica e acessibilidade)
- **CSS3** (Estilização responsiva)
- **JavaScript (Vanilla)** (Manipulação de DOM e dinamismo da SPA)

## 📁 Estrutura do Projeto
- `index.html` - Página inicial e apresentação da ONG
- `projetos.html` - Catálogo de projetos sociais e iniciativas
- `cadastro.html` - Formulário de adesão e voluntariado
- `/css` - Estilos e regras de layout (`style.css`)
- `/js` - Scripts de navegação e validação (`script.js`)
- `/imagem` - Ficheiros de imagem da aplicação
